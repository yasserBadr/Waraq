# ورق | Waraq

قارئ EPUB خفيف ومحمول بواجهة عربية. الإصدار **1.3**.

افتح [dist/Waraq.html](dist/Waraq.html) في Chrome أو Edge، ثم اختر كتاب EPUB من جهازك. الملف مستقل ويعمل دون إنترنت أو تثبيت. يمكنك أيضًا تنزيل المستودع كملف ZIP وفك ضغطه.

## المزايا

- قراءة الفصل بعرض المساحة المتاحة مع تمرير رأسي.
- عرض A4 والتقليب بين الصفحات كخيارين إضافيين.
- دعم EPUB 2 وEPUB 3 والعربية والإنجليزية.
- فهرس، بحث، إشارات مرجعية، واستعادة موضع القراءة.
- أوضاع نهاري وورقي وليلي، وضبط الخط وتباعد السطور.
- تصدير بيانات القراءة واستيرادها ونقلها بين الأجهزة.

الكتب والمواضع محفوظة محليًا في المتصفح؛ لا يرفعها التطبيق إلى خدمة خارجية. نقل ملف التطبيق لا ينقل بيانات المتصفح، لذا استخدم التصدير عند الانتقال إلى جهاز آخر. لا يدعم DRM أو PDF أو MOBI.

## التطوير

المتطلبات: Python 3.10 أو أحدث، وNode.js 18 أو أحدث. المكتبات مضمّنة، ولا يحتاج البناء إلى تنزيل حزم.

```sh
python src/build.py
node scripts/check.mjs
python scripts/package.py
```

- `src/index.html`: الواجهة وكود التطبيق القابلان للتعديل.
- `src/vendor/`: EPUB.js 0.3.93 وJSZip 3.10.1 مع تراخيصهما.
- `dist/`: النسخة المستقلة الجاهزة للتشغيل وكتاب تجريبي أصلي.
- `docs/`: دليل الاستخدام ونتائج التحقق وحدوده.
- `releases/`: حزمة ZIP الناتجة من أمر التحزيم، غير متتبعة في Git.

يختبر أمر الفحص بنية JavaScript، وبيانات القراءة، والإعدادات، ومنطق التنقل والاختصارات. راجع [ملخص التحقق](docs/TESTED.txt) للاطلاع على حدود الاختبارات البصرية واختبارات المتصفحات.

## التراخيص

تراخيص المكتبات المضمّنة محفوظة في `src/vendor/` وداخل ملف HTML المستقل، وفي [THIRD-PARTY-LICENSES.txt](dist/THIRD-PARTY-LICENSES.txt). لم يُحدَّد ترخيص عام مستقل لكود التطبيق.
